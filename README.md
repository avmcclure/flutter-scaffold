# flutter-scaffold

A ready-to-run Flutter web app for live AI coding demos. Pick a subject, rewrite
`lib/content.dart`, and you have an app: searchable list, detail pages,
favorites, a "surprise me" button, and a quiz.

```bash
flutter test
flutter run -d chrome
```

Demo prompt: *"Turn this app into one about &lt;subject&gt;. Only edit lib/content.dart."*
